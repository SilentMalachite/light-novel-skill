# 文体チェック

ラノベらしい日本語か、AI臭くないかを検査する。本文は書き換えない。違反を箇所つきで返す。直すのは「直して」と頼まれたときだけで、手順は [fix.md](fix.md)。

## 手順

1. 機械チェックを実行する。パスはこのスキルのディレクトリ基準。

   ```bash
   python3 scripts/check_style.py 本文.md
   ```

   本文がファイルに無いときは標準入力で渡す。Python が使えないときは下の「機械チェックの項目」を目で見る。
2. 出力の違反を採る。誤検出は理由を1行添えて外す。例: 山場で意図した長文、キャラの口癖としての定型。
3. 「判断の項目」を本文で確かめる。
4. 「返す形」で返す。

## 機械チェックの項目

| 種別 | 見るもの |
| --- | --- |
| 冒頭 | 天気、目覚め、通学路で始まる |
| 章末 | 「こうして」「一日が終わった」の要約締め |
| AI定型 | `style.md` の一覧の語が1話で2回目 |
| 感情ラベル | 悲しかった、緊張していた、で段落が終わる |
| 文末 | 地の文の文末2字が3連続 |
| 句点 | 閉じ括弧前の句点 |
| 比喩 | 1場面で2つ目、または段落を比喩で締める |
| 長文 | 地の文の1文が60字超 |
| 説明 | 地の文の1段落が120字超 |
| の連続 | AのBのCのD |
| 記号 | 本文中の太字記法、絵文字 |

最後の行に会話比率と地の文の平均文長が出る。Web は会話30〜45%、平均文長は40字前後までを目安にする。

## 判断の項目

| 項目 | 合格 | 要修正の例 |
| --- | --- | --- |
| テンポ | 地の文が動作、感覚、短い判断で進む | 説明や回想で場面が止まる |
| 一人称の地の文 | 視点人物の語彙と温度で書かれている | 誰が語っても同じ地の文 |
| 口調 | 話者タグを外しても誰か分かる | 全員が同じ丁寧さ、同じ語尾 |
| 掛け合い | 会話がキャラの関係やズレを見せる | 情報の受け渡しだけの会話 |
| 見せる | 感情を動作と身体で出す | 感情の名前で説明する |
| 説明 | 設定は選択を縛る場面でだけ出る | 設定の講義、説明台詞 |
| AI臭さ | 具体的な物と動作で書かれている | 「静寂が辺りを包んだ」のような誰でも書ける美文、同じ構造の対句、三つ並べの列挙、段落ごとの要約、「本当の戦いが始まろうとしていた」のような予告調の締め |
| 冒頭と章末 | 冒頭でジャンル、視点人物、欠落、フックが読める。章末に未解決が1つ | 世界観の講義で始まる、解決して終わる |

## 返す形

```text
- [文末] 13行目: 地の文の文末「いた」が3連続。1つ変える。
- [テンポ] 15〜17行目: 設定説明で場面が止まっている。主人公の選択に絡む一文だけ残す。

判定
- テンポ: 要修正（15〜17行目）
- 一人称の地の文: 合格
- 口調: 合格
- 掛け合い: 要修正（19〜24行目）
- 見せる: 合格
- 説明: 要修正（15行目）
- AI臭さ: 要修正（5, 9, 19行目）
- 冒頭と章末: 要修正（3, 23行目）

会話比率 14% / 地の文の平均文長 24.6字
```

返すのは違反一覧、判定、統計の3つだけで、この順に並べる。違反は機械チェックと判断の項目を行順に混ぜる。修正案は1違反につき1行まで。点数は付けない。

前置き、統計の後の講評や補足は付けない。会話比率が目安から外れていても、統計の行に数字を出すだけにする。上の例のコードブロックは形を示すためのもので、返すときは囲まない。
