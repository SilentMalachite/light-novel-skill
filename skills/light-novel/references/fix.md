# 文体の修正

推敲で「直して」「書き換えて」「AI臭さを消して」と頼まれたときの手順。文体チェックの違反を、筋を変えずに最小限で直す。「チェックして」だけの依頼では使わない。

## 手順

パスはこのスキルのディレクトリ基準。本文がファイルに無いときは、作業ディレクトリに書き出してから始める。

1. 元の本文を控える。`本文.md` を作品フォルダの外の一時ディレクトリに `元.md` として複写する。作品フォルダに控えを残さない。
2. 機械的に直せる違反を直す。

   ```bash
   python3 scripts/check_style.py --fix --json 本文.md
   ```

   句点と記号だけが直り、本文に書き戻る。残りの違反が `findings` に、行番号と該当箇所（`match`）つきで出る。
3. 残った違反を「直し方」の表に沿って直す。直すのは違反のある文だけ。前後の文は触らない。
4. `check.md` の「判断の項目」で要修正のものも直す。口調は `characters.md` に口調サンプルがあるときだけ直す。
5. 再検査する。

   ```bash
   python3 scripts/check_style.py --baseline 元.md 本文.md
   ```

   次のすべてを満たせば終わる。満たさないときは 3 に戻る。3〜5 は3回まで。
   - 残った違反が、「直し方」の表で「直さず報告する」と決めたものだけ
   - 「新規」が「なし」。違反は種別と該当箇所の組で突き合わせるので、同じ種別でも別の箇所に出たものは新規に数え、行番号が付く
   - セリフの変更が無いか、口調サンプルに合わせて語尾を変えたものだけ
   - 字数に「要確認」が付いていない

   残す違反が無く、セリフも変えていなければ、終了コードは 0 になる。
6. 「返す形」で返し、`元.md` を消す。

Python が使えないときは 2 と 5 を `check.md` の「機械チェックの項目」と下の「変えないもの」を目で見て行う。

## 直し方

| 種別 | 直し方 | 直さず報告するとき |
| --- | --- | --- |
| 句点 | スクリプトが直す | なし |
| 記号 | スクリプトが直す | なし |
| AI定型 | 2回目以降を、その場の動作か物に置き換える。1回目は残してよい | キャラの口癖 |
| 感情ラベル | 段落末の感情語の文を、身体か動作の文に置き換える | なし |
| 文末 | 3連続目だけ変える。体言止め、現在形、語順の入れ替えのどれか | なし |
| 比喩 | 2つ目の比喩は消す。段落の締めの比喩は消すか、事実か動作にする | なし |
| 長文 | 2文に割る | 山場で意図した長文 |
| 説明 | 文を割り、段落を2つ以上に分ける。設定は選択を縛る分だけ残す | 削ると既出事実が消えるとき |
| の連続 | 語順を変えるか、「にある」や読点で切る | なし |
| 冒頭 | 天気や目覚めの文を後ろに回し、セリフかフックの文を先頭に出す | 本文にフックになる文が無い |
| 章末 | 要約の文を消し、その前の未解決で切る | 消すと未解決が残らない |

置き換えの例。

| 種別 | 直す前 | 直した後 |
| --- | --- | --- |
| AI定型 | 「ねえ、聞いて」ユイの声に、俺は再び息を呑んだ。 | 「ねえ、聞いて」ユイの声に、俺は振り返った。 |
| 感情ラベル | 俺は嬉しかった。 | 俺は布団を蹴って起き上がった。 |
| 文末 | 考えていた。空を見ていた。ユイのことを思っていた。 | 考えていた。空を見ていた。頭にあるのはユイのことばかりだ。 |
| 比喩 | 青空が広がっていた。まるで今日を祝福しているかのようだった。 | 青空が広がっていた。 |
| の連続 | 王都の学園の中庭の噴水の前で | 王都にある学園の中庭、噴水の前で |
| 章末 | （最終行）こうして、俺たちの新しい一日が終わった。 | （その行を消し、前の未解決で切る） |

`tests/fixtures/ai_like.md` を直した全体の見本が `tests/fixtures/ai_like_fixed.md` にある。

## 変えないもの

- 出来事の順序と結果
- 固有名詞、能力、時間などの既出事実。`plot.md` と `characters.md` があれば照らす
- セリフの中身。句点、！？、…は変えてよい。読点、中黒、ダッシュを変えると比較にセリフの変更として出る。口調サンプルに合わせて語尾を変えたときも出るので、1件ずつ語尾だけの変更か確かめる
- 視点と一人称
- 字数は元の±15%以内

新しいキャラ、設定、出来事、比喩を足さない。直せない違反は書き換えで逃げず、報告する。

比較が見るセリフは、1行に収まった「」と『』の中身だけ。行をまたぐセリフは比較に出ないので、目で確かめる。

## 返す形

本文はファイルを上書きし、チャットには出さない。チャットには次だけを返す。

```text
直した: 7件（句点 1, 比喩 2, 感情ラベル 1, 文末 1, AI定型 1, 章末 1）
残した:
- [長文] 31行目: 山場の独白。意図した長文として残す。
- [冒頭] 3行目: フックになる文が本文に無い。場面の入りから見直す。
字数 3120 → 3015（-3%）/ セリフ変更なし
```

残した違反が無ければ「残した」の行は書かない。差分の解説、代替案、書き換えた理由は頼まれたときだけ出す。
