# 構成

## 順序

本文より先に、次の順で固定する。

1. ログライン1行。誰が、何を失いまたは欲し、何に阻まれ、何をする話か。
2. 一行コンセプト。売り。例: 魔王が時給で働く。
3. 結末。最終的に何が残り、何が失われるか。
4. クライマックス。結末を確定させる場面。
5. あらすじ800字以内。結末まで書く。内部用プロットは4000字まで。
6. 話ビート。各話の目的と章末フック。
7. 場面カード。

結末が無い状態で本文を書かない。

## 比率

目安であり、契約ではない。

- 起承転結: 起10 / 承40 / 転40 / 結10
- 序破急: 序10 / 破80 / 急10

中盤が説明で膨らんだら、選択を迫る障害に置き換える。

## 場面カード

1シーン1ブロック。本文に混ぜない。空欄があるシーンは書かない。

```text
- 視点人物:
- 場所・時刻:
- 目的（視点人物がこの場で欲しいもの）:
- 入口の圧:
- 障害:
- 結果（成功 / 失敗 / 代償）:
- 状態変化（情報・関係・身体のどれが変わったか）:
- 出口の未解決:
- 守る既出事実:
```

心情だけのシーンは禁止。変化が無いシーンは削除する。

## 章

- 1章は場面カード2〜4枚を目安にする。
- 章末フックは、未解決の問い、危機、意外な一言、選択の未決のどれか1つ。
- 伏線は仕込み時に回収予定の話をメモする。未回収のまま終えない。
- 回想は短く、現在へ戻す合図を置く。

## 冒頭

最初の場面で、ジャンル、視点人物、欠落、フックの4つが読めること。世界観の講義で始めない。
